# 语音识别、取消与纠正

状态：0.19.1（build 37）将输入与输出决定绑定到本轮，并校验兼容声线的转写。更新于 2026-11-18。约束见[产品基线](../product.md)与[自然话轮](../001-natural-voice-turns/spec.md)。

## 问题与目标

用户用 USB/有线耳机独自说中文，仍频繁发生错误识别；“给我画一张图片”被转成“今天画上的故事”，随后生成无关故事。此前延长续说窗口只能处理分段，不能提高识别准确率。通话目前也缺少明显的取消本轮和纠正入口。目标是提高有效语音输入的准确性，并让用户可以阻止、撤回、改正错误输入带来的动作。

## 设计决定

2026-11-18 面向低龄儿童的有声兜底与语音安全对称修复：
- **同音代词与句首语气词宽容比对**：中文声学上完全相同的代词（`他/她/它`、`你/妳`）、句尾常见语气助词（`啊/呀/啦`）以及足够长句子（正文至少 3 字）前的口头起音词（`嗯/呃/哦/噢`）不再视为字词冲突，直接采纳音频复核文本，避免无谓的第三次确认或拒答；真实字音差异（如“举/许”“疑/一”）仍严格复核。
- **不识字儿童有声重说提示**：当识别失败、超时、音频缺失或三次候选仍不一致时，除保留可修改预览文字外，本机老师声线在当前无其他播放时播报简短温和的重说提示（“刚才没太听清，可以再跟莉莉说一遍吗？”），孩子再次开口、静音、停止或发文字时立即打断提示音，且绝不向云端模型请求错误回复。
- **电话通道本机安全对称拦截**：复核后的用户语音文本在写入服务端上下文与请求回答前，先移除原始音频项并执行与文字入口相同的本机隐私保护（`Safety.shouldProtectUserInput`）与风险评估（`Safety.isRisk`），拦截时不把隐私原文留在会话历史中，改由本机温和提示并保持通话；助手文本回复在朗读与存档前同样拦截联系方式、风险词、无故推给大人（`containsAdultHandoff`）及虚构照片上传承诺。

2026-11-17 用户再次实测：常见诗句识别错误，实时预览正确后最终输入反而改错。排查开始时安装包为 0.17.1，哈希与此前交付记录一致，未发现版本回滚；确认现有逐段复核缺少候选冲突处理，不能用此前合成样例通过推断真人识别可靠。本轮实现与验证见下方 0.17.3 记录。

- 实时完整转写与音频复核字词不一致时，保留预览，使用同一份音频再确认一次；两份候选和同轮前文只作识别参考，不把任一候选当答案。确认须与其中一份一致才能提交；仍有歧义、失败或超时则保留可修改文字并提示，不悄悄覆盖后执行。标点差异不增加确认请求，明确停止仍可立即生效。
- 最终识别携带有限的同轮前文，不能依靠孤立音频片段猜新名字；不加入本次测试的标准答案或把诗库原文强写进用户输入。

- 保留持续双工、1.6 秒续说窗口、对象判断和 A「温柔老师」（2026-11-17 用户实测后将等待从 2 秒调短，见自然话轮规格）。`gpt-live-transcribe / medium` 负责输入预览和及时让话；`gpt-transcribe` 直接复核音频并形成最终输入。不能让文字模型根据故事猜测或改写原话。界面区分“暂时听到”与最终文字；本轮未接入新供应商或 Codex 专用私有接口。
- 用有界内存保存本通话近期的 24 kHz 单声道 PCM（120 秒窗口），按服务端的音频时间戳提取片段，保留至多 120 ms 额外起始余量；录音不落盘。最终复核在片段结束后尽早启动，与实时转写并行，单段复核截止为 8 秒；分段后的前后文仍按自然话轮规则合并。音频缺失、超时或识别失败时提示重说/修改，不悄悄把临时字幕当最终请求。
- 当前设备核对为 JBL TUNE 305C USB-C，同时承担系统默认输入和输出。保留 Mac 的回声消除和自动增益；云端不再固定叠加远场降噪。实时字幕采用兼顾准确率的档位，最终复核独立于字幕。
- 接话前将服务端原始音频输入替换为同一份最终文本，显示、意图/画图判断及回答统一使用它。最终文本与用户撤回/修改后的文本优先，不能让对话模型另听一遍后按不同意思执行。
- 主窗口与桌宠都提供明显的“停下”按钮：立即停止当前播放、生成及待执行工具，保持电话接通。输入预览提供“取消这句”和修改入口；最近的语音输入提供“重说 / 修改”入口（2026-11-19 起按用户要求，原“改文字”按钮统一改名为“修改”），取消相关旧工作后按用户修正重新处理。挂断、静音仍分别承担原有用途。
- 取消是本机立即生效的动作；异步转写、模型、工具和播放的迟到回调必须经过轮次校验。被撤回的输入与相关回复不继续影响当前模型上下文，不因断网而继续播放或重启旧任务。
- 撤回修复当前轮的消息和模型上下文，并取消未完成工作；已经完成并保存的历史故事/图片仍使用既有的会话删除入口管理，不跨轮清空历史。
- 不用热词注入测试答案。评测分开记录识别字错、关键意图、漏听、无声误触发、反应时间及取消后的晚到结果，保留失败样例。

## 参考与边界

- 实际检查本机 ChatGPT/Codex 安装包的语音与宠物相关代码：客户端独立管理输入/输出音频、delta/done 转写、连接阶段输入缓冲与预留起始音频，以及会话取消/状态清理。包中专用语音模型和服务端行为不是可直接复用的公开 API，也不能据此声称获知其中文识别率。只参考机制，TinyTales 保持独立实现。
- [Pipecat STT 管线](https://docs.pipecat.ai/pipecat/learn/speech-to-text)：识别文本先进入用户上下文，再进入语言模型；识别服务可以独立更换。
- [LiveKit 话轮调优](https://docs.livekit.io/agents/logic/turns/tuning/)：把结束判断、打断、误打断恢复和音频预处理分别处理。
- [OpenAI 转写](https://developers.openai.com/api/docs/guides/speech-to-text)：用准确率优先转写处理完整音频，语言和上下文提示不能代替音频证据。

不把合成高音等同于真实儿童声音，不把直接 PCM 回放等同于 USB 麦克风现场测试。真实用户原声暂不可得；只用虚构文字、固定合成音频调用真实接口。实际设备核验只保留拓扑与统计，不保存或上传环境录音。

| VR-011 | 常见同音代词与句首语气词差异直接采纳复核文本，不触发多余确认；识别失败或候选仍冲突时，本机老师声线温和提示重说，新开口立即打断提示且不发起云端回复。 |
| VR-012 | 电话复核输入在提交前拦截本机隐私与风险内容并清理原音频项；助手输出在朗读与存档前拦截无故找大人、联系方式与虚构照片上传承诺，通话保持可用。 |
| VR-013 | 隐私转写不进入意图分类请求，已拦截的原话不随电话或文字历史重发。电话内打字与口述共用风险判断；停止、静音、挂断或新轮次使旧复核失效。 |
| VR-014 | 输出校验同时约束字幕、播放和存档。真实危险中的合理求助提示可以发布，普通聊天中的无故求助和不适合输出的内容不能发布。兼容云端声线先核对转写再播放对应音频。 |
| VR-015 | 撤回只撤销该语音轮实际写入的书签。读取先前保存的书，撤回后仍可找到原文和配图；不同会话的后续写入不得被旧轮回滚。 |

0.19.1 修改原因：复核曾晚于意图分类、播放或下一轮开始。已知文字在送往下一项服务前检查，异步决定绑定发起它的输入。口述音频仍由已连接的转写服务处理。

最终代码 **9/9 场景通过**，全部使用固定合成输入；真实调用转写、对象判断与对话接口，输出播放时序由夹具模拟：
