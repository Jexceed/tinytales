# 成语与古诗词资料

状态：已实现；0.17.3 增加近似诗句的待确认参考，代码和真实文字接口通过，已安装并通过隔离启动检查；保留当前聊天进程，重新打开后使用新版。原有资料出处和版本保持。更新：2026-11-17。产品基线：[product.md](../product.md)。

## 需求与变更原因

用户希望讲成语、古诗词和相关故事时更准确可靠。现有资料只有故事开头与词卡，典故、诗文主要依靠模型记忆。增加一份随 App 发布、可追溯的精选资料，用同一套检索供文字与电话使用。

## 设计决定

- 2026-11-17：用户把“举头望明月”说成语音输入后显示为“许头望明月”，精确检索未命中。对至少五字的已收录诗句，只差一次增字、删字或换字的输入提供 possible_misheard_quote 候选，仅供简短确认；不改写输入、不冒充精确匹配、不把候选编造成新角色。用户明确在编角色或否认诗句时不强行套用。超过一次字词编辑不作此候选保证。

- 首批收录 8 个成语、8 首古诗。每条包含稳定 ID、名称及别名、分类、公共领域原文或典源摘句、出处、核对链接和日期、适龄解释、主题、容易讲错的地方。古诗额外保留作者、时代及版本说明；成语保留拼音和典故梗概。现代解释与例子自行编写，不复制现代儿童故事书。
- 使用教育部门公开的古诗选本与成语辞典核对，通行异写另参考人教社网站所载文本；这是开发时的资料核对，不宣称专家审定、覆盖全部异文或已完成儿童教学验证。
- 资料随可执行程序编译，App 不在文稿中寻找运行资源，不新增网络下载或配置。知识读取不写数据库、不保存个人信息。
- 共享 `lookup_classics` 工具按篇名、别名、原文短句或主题检索，返回最多 3 条记录。输入明确提到收录篇名/诗句，或明确要求成语/古诗并带已知主题时，本机先把对应资料交给模型，减少对模型改写查询词的依赖。未命中时返回明确的无匹配状态和已收录目录，模型可选相关篇名重查，不能凭相似标题编造原文，也不能把单次主题查询失败说成整个主题没有资料。
- 文字与电话均遵循同一内容规则：原文、作者、出处按资料；白话解释保持通俗；原典和受其启发的创作分开，新增角色或对白须自然说明是改编。背诵不能改字拼句；不为古诗编造确定的创作现场或诗人生平。
- 不把资料库变成固定课堂或首页内容大厅。普通故事不强行插入成语，适合当前兴趣时才引用；扩充资料需人工核对再发布。

## 验收与追踪

| ID | 验收场景 |
| --- | --- |
| CK-001 | 精选资料结构完整、ID 唯一，原文、作者和典源关键事实可回归检查；解释、改编边界与出处随条目返回。 |
| CK-002 | 篇名、繁简体、别名、诗句和主题可检索；不相关请求返回空，不把模糊匹配伪装成精确命中。 |
| CK-003 | 文字实际请求自动获得明确匹配资料；共享工具可查主题和处理未收录；普通对话不塞入整份资料。 |
| CK-004 | 电话实际请求和工具往返使用同一资料及规则；新话题不沿用上轮资料，文字输入与语音输入都可查用。 |
| CK-005 | 近似诗句返回待确认候选而非精确命中，普通故事及明确否认不强行套用；文字与电话提示均不得据此改写用户输入。 |

## 验证与边界

2026-11-17：CK-005 通过原生及电话集成回归。真实文字接口对“许头望明月”和“一是地上霜”均先问是否指《静夜思》的对应原句，没有把错字编成人物。[近似诗句](../../artifacts/v0173-voice-regression/classics-near.json)、[同音误字](../../artifacts/v0173-voice-regression/classics-homophone.json)。完整电话回放的正确诗句也获得原文参考；识别模型仍有错误，不能把知识候选核对等同于准确收音，详见[语音验证](../007-voice-reliability/spec.md)。

2026-11-16：原生 122/122、电话 79/79 代码回归通过，包含 CK-001～CK-004。原生测试覆盖实际 `CompanionEngine.turn` 的提示词及工具往返；电话测试覆盖实际 `response.create` 的资料注入、下一轮清除和工具回包，使用模拟连接与音频。

真实 Responses 接口的 6 个固定文本样例通过：静夜思全文及作者、草的完整八句、亡羊补牢释义和出处、掩耳盗铃的钟/铃区别、按植物主题检索成语、虚构篇名未收录。使用默认文本模型与独立临时数据库，不读取用户对话、不打开麦克风。证据：[接口样例](../../artifacts/v016-address-classics/tinytales-classics-live.json)。

其中完整八句的答复明确说明课本常选前四句，但没有逐字说“八句”，被原先的措辞断言误报。已修正断言为全文逐字一致且解释节选，重新核验同一份真实答复；没有改写接口输出。[原始判定记录](../../artifacts/v016-address-classics/classics-before-checker-fix.json)保留。

资料不能保证模型每次都严格遵守，未收录条目与真实多轮教学效果不纳入首批完成范围。本轮尚未对全部 16 条进行真实模型逐条复核，也没有验证全部诗句在真实电话中的朗读、物理设备或用户听感。知识原文核对、模型生成准确性、普通话朗读与用户听感分别验证。

安装包为 0.16.0（build 27），知识资料编译在 App 中，不依赖文稿目录。签名、安装哈希、原有授权和正常启动检查通过，见[安装核对](../../artifacts/v016-address-classics/install-check.json)与[正常启动](../../artifacts/v016-address-classics/normal-launch-check.json)。

## 首批目录与出处

- 成语：守株待兔、揠苗助长（拔苗助长）、画蛇添足、亡羊补牢、刻舟求剑、掩耳盗铃、自相矛盾、井底之蛙。按[教育部《成语典》](https://dict.idioms.moe.edu.tw/idiomView.jsp?ID=39&webMd=2)逐条核对典源，各条独立链接保留在[知识资料](../../macos/Sources/ClassicalKnowledge.swift)。
- 古诗：咏鹅、春晓、静夜思、登鹳雀楼、赋得古原草送别、游子吟、悯农（其二）、小池。按香港教育局建议篇章核对，例如[静夜思](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/recommended-passages/KS1_10.pdf)、[赋得古原草送别](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/recommended-passages/KS1_11.pdf)；悯农的餐/飧、登鹳雀楼的雀/鹊在条目中注明采用版本及核对链接。

短篇名《草》只在明确篇名语境命中，不把草地或小池塘当成古诗；《悯农》其一尚未收录，不拿其二替代。主题/作者检索结果标为相关参考，不能充当未命中篇目的原文。
