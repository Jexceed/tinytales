# 成语与古诗词资料

状态：0.19.1 已逐条校对新增的 8 个成语和 8 首古诗，精选资料共 32 条。更新于 2026-11-18。产品基线见 [product.md](../product.md)。

## 需求与变更原因

用户希望讲成语、古诗词和相关故事时更准确可靠。现有资料只有故事开头与词卡，典故、诗文主要依靠模型记忆；且首批 16 条未覆盖《悯农（其一）》《古朗月行》《咏柳》《风》《江南》《狐假虎威》等学龄前高频篇目。现扩充随 App 发布、可追溯的精选资料至 32 条（16 个成语、16 首古诗），用同一套检索供文字与电话使用。

## 设计决定

- 2026-11-18 学前高频资料扩充：新增 8 个高频成语（狐假虎威、对牛弹琴、叶公好龙、杯弓蛇影、水滴石穿、百发百中、熟能生巧、愚公移山）与 8 首高频古诗（悯农（其一）、咏柳、风、江南、古朗月行（节选）、山村咏怀、敕勒歌、江雪），共 **32 条**。其中《悯农（其一）》与《悯农（其二）》分别独立建档，明确点名其一/春种一粒粟或其二/锄禾日当午时严格命中对应篇目，互不串用；单字题《风》与《草》同样要求明确篇名或诗句语境，不因日常“刮风”误触发；《古朗月行（节选）》明确标注原诗十六句、课本节选前四句。
- 2026-11-17：用户把“举头望明月”说成语音输入后显示为“许头望明月”，精确检索未命中。对至少五字的已收录诗句，只差一次增字、删字或换字的输入提供 possible_misheard_quote 候选，仅供简短确认；不改写输入、不冒充精确匹配、不把候选编造成新角色。用户明确在编角色或否认诗句时不强行套用。超过一次字词编辑不作此候选保证。

- 精选目录包含 16 个成语、16 首古诗。每条包含稳定 ID、名称及别名、分类、公共领域原文或典源摘句、出处、核对链接和日期、适龄解释、主题、容易讲错的地方。古诗额外保留作者、时代及版本说明；成语保留拼音和典故梗概。现代解释与例子自行编写，不复制现代儿童故事书。
- 古诗按条目所引选本、古籍正文及署名考证核对，成语核对《成语典》的典源或书证，读音异文附对应辞典；这是开发时的资料核对，不宣称专家审定、覆盖全部异文或已完成儿童教学验证。
- 资料随可执行程序编译，App 不在文稿中寻找运行资源，不新增网络下载或配置。知识读取不写数据库、不保存个人信息。
- 共享 `lookup_classics` 工具按篇名、别名、原文短句或主题检索，返回最多 3 条记录。输入明确提到收录篇名/诗句，或明确要求成语/古诗并带已知主题时，本机先把对应资料交给模型，减少对模型改写查询词的依赖。未命中时返回明确的无匹配状态和已收录目录，模型可选相关篇名重查，不能凭相似标题编造原文，也不能把单次主题查询失败说成整个主题没有资料。
- 文字与电话均遵循同一内容规则：原文、作者、出处按资料；白话解释保持通俗；原典和受其启发的创作分开，新增角色或对白须自然说明是改编。背诵不能改字拼句；不为古诗编造确定的创作现场或诗人生平。
- 不把资料库变成固定课堂或首页内容大厅。普通故事不强行插入成语，适合当前兴趣时才引用；扩充资料需人工核对再发布。

## 验收与追踪

| ID | 验收场景 |
| --- | --- |
| CK-001 | 精选资料结构完整、ID 唯一，原文、作者和典源关键事实可回归检查；解释、改编边界与出处随条目返回。 |
| CK-002 | 篇名、繁简体、别名、诗句和主题可检索；不相关请求返回空，不把模糊匹配伪装成精确命中。 |
| CK-003 | 文字实际请求自动获得明确匹配资料；共享工具可查主题和处理未收录；普通对话不塞入整份资料。 |
| CK-004 | 电话实际请求和工具往返使用同一资料及规则；新话题不沿用上轮资料，文字输入与语音输入都可查用。 |
| CK-005 | 近似诗句返回待确认候选而非精确命中，普通故事及明确否认不强行套用；文字与电话提示均不得据此改写用户输入。 |
| CK-006 | 用书名号明确指定作品时，按完整篇名或别名检索。含已收录篇名字样的其他作品不能冒用原文；明确的古诗请求可获知未收录，混合询问能辨认实际命中的作品。普通自编故事不因使用书名号就注入资料。 |
| CK-007 | 扩充后的 32 条学前成语与古诗资料完整可检索；《悯农（其一）》与《悯农（其二）》严格区分不串句，单字篇名《风》在普通日常语境下不误注入，《古朗月行（节选）》保留节选边界说明。 |
| CK-008 | 新增的 16 条资料都有逐条核过篇名和原文的具体来源，离线回归固定条目与来源的对应。《杯弓蛇影》的摘引和故事人物属于同一版本，古诗节选和异文在资料中注明。 |

0.19.1 修改原因：原来的链接格式检查未能发现篇目错配。改为逐条核对辞典与原作，按实际选本修订摘引、人物及版本说明。

真实回放中，模型拿到《静夜思》的资料后仍有一次把“许头”猜作人名。对只陈述一行、与唯一已收录诗句相差一字且没有明确角色设定的输入，文字和本机老师直接用原句询问，兼容声线按同一确认句朗读。原始输入保留供改正。背诵某一首的验收检查实际诗文与所属篇目。

2026-11-18 检查发现，《静夜思续篇》能通过子串命中《静夜思》，作者或外部诗句也可能抢过指定篇名。自动资料与显式工具共用完整篇名的判断，未加书名号的诗句、作者和主题仍可检索。

真实复测还发现，模型会把本轮书名号去掉，再用“静夜思续篇”调用工具，进而背出另一首。工具需结合本轮点名的作品理解改写后的查询。只请求未收录篇目的原文时，可以说明收录情况，等用户选好其他作品再背。

安装包为 0.16.0（build 27），知识资料编译在 App 中，不依赖文稿目录。签名、安装哈希、原有授权和正常启动检查通过，见[安装核对](../../artifacts/v016-address-classics/install-check.json)与[正常启动](../../artifacts/v016-address-classics/normal-launch-check.json)。

## 精选目录与出处

- 成语（16 条）：守株待兔、揠苗助长（拔苗助长）、画蛇添足、亡羊补牢、刻舟求剑、掩耳盗铃、自相矛盾、井底之蛙、狐假虎威、对牛弹琴、叶公好龙、杯弓蛇影、水滴石穿（滴水穿石）、百发百中、熟能生巧、愚公移山。按[教育部《成语典》](https://dict.idioms.moe.edu.tw/idiomView.jsp?ID=39&webMd=2)等典源核对，各条独立链接保留在[知识资料](../../macos/Sources/ClassicalKnowledge.swift)。
- 古诗（16 首）：咏鹅、春晓、静夜思、登鹳雀楼、赋得古原草送别、游子吟、悯农（其一）、悯农（其二）、小池、咏柳、风、江南、古朗月行（节选）、山村咏怀、敕勒歌、江雪。原有选篇采用香港教育局建议篇章及人教社通行文本，例如[静夜思](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/recommended-passages/KS1_10.pdf)、[赋得古原草送别](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/recommended-passages/KS1_11.pdf)；悯农的餐/飧、登鹳雀楼的雀/鹊、敕勒歌的见（xiàn）等在条目中注明采用版本及读音说明。新增古诗的七条引用链接固定到核对过的原作修订本，《山村咏怀》附通行全文及署名考证。

短篇名《草》《风》只在明确篇名语境命中，不把草地、刮风或小池塘当成古诗；《悯农》其一与其二独立建档，明确指定其一或其二时互不替代。主题/作者检索结果标为相关参考，不能充当未命中篇目的原文。
