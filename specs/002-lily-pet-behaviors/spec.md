# 莉莉的桌面陪伴行为

状态：已实现并安装桌宠补丁 0.12.1（构建 23）。日期：2026-11-13。产品基线：[product.md](../product.md)。

## 问题与目标

用户反馈桌宠行为单一。原实现待机仅眨眼和呼吸，鼠标靠近切换一张倾听姿态，点击/拖动短暂切换挥手和跳跃。增加有节奏的日常小动作与可发现的互动，让莉莉像陪在桌边的伙伴，同时保持原生界面、彩虹独角兽身份和对话优先。

## 行为与设计决定

- 空闲时，在张望、看书、伸懒腰、轻轻摇摆、玩星星中随机轮换；一轮不重复，相邻两轮也不连续重复同一种动作。每个动作约 3～8 秒，之间休息 12～22 秒。连续空闲至少 90 秒后才允许约 12 秒的短暂打盹。
- 鼠标靠近时短暂招呼，停留后恢复平静；招呼有冷却，不因指针抖动反复触发。轻轻来回摸过莉莉会有开心与小爱心回应。拖动继续用于摆放桌宠，放下有轻巧落地反馈。
- 右键菜单提供“摸摸莉莉”“一起玩星星”“安静陪伴/恢复小动作”，不需要猜手势。原来的单击快捷聊天、双击主窗口、拖动位置、底部居中电话保持。
- 单击在系统双击判定窗口结束后打开快捷聊天，双击只打开主窗口；拖拽不触发聊天。关闭菜单也不被误判为鼠标重新靠近。
- 新增持久化“空闲小动作”设置，旧设置默认开启；“靠近时回应”关闭后不再触发靠近招呼或悬停抚摸，显式菜单仍可互动。安静陪伴停止自发动作，保留用户主动互动。
- 录音、连接、思考、讲话和错误状态优先于所有装饰行为；通话静音或等待期间也不插入空闲表演。聊天弹窗/菜单打开和拖拽时不自行表演。被打断的表演丢弃，不在通话结束后重放。
- 系统“减少动态效果”关闭自发动作、位移、缩放、旋转和粒子运动；显式互动可短暂显示静态表情。隐藏桌宠停止动画计时；恢复或机器睡眠唤醒后重新等待，不补播过期动作。
- 复用六张莉莉姿态，以原生姿态编排、轻微变换和少量星星/爱心呈现动作；兼容已有导入图集，主界面静态头像不参加自发表演。动作只发生在原画布内，桌宠及按钮不游走。
- Git 仓库包含原创莉莉图集；历史本机导入的 Hoots 图片保留在本机，不随公共仓库再分发。PB-006 和导入图集解码回归改用程序生成的同尺寸彩色图集，继续验证动画行、视线行和裁切边界；不改已有用户导入功能。
- 空闲动作标签短暂描述正在做什么，结束回到“找我聊天”。不主动发出声音、发送消息、生成故事或调用模型；不引入饥饿值、情绪惩罚或催促陪玩的文案。

## 验收与追踪

回归测试位于 [PetBehaviorTests.swift](../../macos/Tests/PetBehaviorTests.swift)，注册到原生测试集；名称包含稳定 ID。

| ID | 必须验证的行为 |
| --- | --- |
| PB-001 | 空闲动作有休息间隔，轮换覆盖多种行为且无连续重复；短时空闲不打盹。 |
| PB-002 | 靠近招呼有冷却；抚摸需要真实移动，关闭靠近回应后不触发；显式互动有有限时长。 |
| PB-003 | 连接/录音/思考/讲话/错误与静音通话优先，旧互动不会恢复；弹窗和拖拽抑制自发行为。 |
| PB-004 | 安静陪伴立即停止自发动作，显式互动仍有效；旧设置迁移及重启保存保留其它偏好。 |
| PB-005 | 减少动态效果时无自发动画和几何/粒子运动；隐藏和唤醒丢弃过期动作。 |
| PB-006 | 六姿态及导入图集的映射有效，动作首尾平稳，几何幅度受限、无窗口自动位移。 |
| PB-007 | 单击、双击和拖动的回调不串扰，菜单互动不发送聊天或接通电话；桌宠状态反馈可读取。 |

- 原生回归 **94/94**，其中 10 个桌宠场景覆盖 PB-001～PB-007：使用确定性时钟验证轮换、间隔、冷却、抚摸识别、通话抢占、隐藏、唤醒、减少动态效果、设置迁移、图集映射和原生单击/双击/拖拽事件。证据：[原生日志](../../artifacts/v013-pet/native-tests.log)。

- 独立构建的规格链接及 16 个验收 ID 追踪通过；九种行为使用实际 `PetCanvas` 渲染，检查画布边界、短标签和动作首尾。证据：[九种动作预览](../../artifacts/v013-pet/behaviors/gallery.png)、[时序画面](../../artifacts/v013-pet/behaviors/timing.png)、[减少动态效果](../../artifacts/v013-pet/behaviors/reduced-motion.png)、[设置界面](../../artifacts/v013-pet/settings.png)。
- 自动化操作真实原生窗口，观察到右键摸摸的爱心、玩星星的动画和对应标签；安静模式菜单正确切换，测试后已恢复默认开启。已安装 App 重启后再次观察到摸摸回应及新菜单。没有发送聊天、接通电话或打开麦克风。

交付范围：共享工程同时进行 0.13 双工语音修复。桌宠补丁独立基于已通过回归的 0.12 语音代码构建，未覆盖共享工程的新语音规格或后续改动。该构建的源文件归档在 [release-source](../../artifacts/v013-pet/release-source)，依赖原工程已有资源；共享工程下一次构建继续包含本桌宠功能。94/62 是此桌宠快照的结果，不代表并行语音修复完成。
