# 对话里的画图

状态：已实现；代码、真实接口回放、0.14.0 安装及原生界面截图检查通过。日期：2026-11-14。产品基线：[product.md](../product.md)。

## 问题与目标

用户报告多次说“画图”仍只有文字解释。已有实现漏判“你画图吧”等口语；生图工具要求 `StorySession.current` 已存在，语音里并非每段虚构情节都触发存档，导致把未存档误当成没有画面依据。文字入口还可能过滤掉工具。模型随后解释“先讲完并保存”而没有生成图片。

画图应当直接完成用户当前的画面请求，普通故事对话不用先存档。兼顾画质和效率，不靠无反馈地等待或重复确认。

## 设计决定

- 文字、语音共用画图请求：本轮原话、同一会话最近的实际对话、当前故事摘要。最新指定主体/纠正优先，不能把另一个旧故事混进来；原始对话只用于进程内选景，不作为图片元数据持久保存。
- “画图吧”“生成一张图”“我想看小火车的图片”等自然表达可进入生图；明确命名的图库素材仍可打开。故事里角色在画画、仅讨论绘画、明确不要画图不触发生成。
- 常见明确表达走直接生图路径，其余表达仍允许模型选择生图工具，不能把关键词表当作工具准入门槛。选景阶段再次确认用户确实在要求出图，明确的拒绝和故事内画画在本机排除。
- 明确画图时可靠地执行工具，不能仅口头承诺。没有存档时仍可根据刚讲过的场景或用户指定主体生成；真的没有可用主体时只问想画什么，不能要求先保存、先找大人或拿不相关图库替代。
- 模型先把输入整理为一个时刻、一个地点的画面与简短中文题名，保留角色数量、外形、关键物件和关系。图片元数据只保存整理后的虚构画面，不保存原始聊天。
- 默认目标为精致、亲和的儿童绘本：柔和层次、细腻材质、清晰表情、明确主体与有节制的背景细节。不是简单色块，也不堆杂物；不生成字幕、拼贴或重复主角。
- 比较当前模型与适合交互的图像模型，实测后确定默认质量。保留 1536×1024 横幅，优先使用高质量 JPEG 减少传输和解码开销。参数依据 [OpenAI 图像生成指南](https://developers.openai.com/api/docs/guides/image-generation)；官方模型说明不能代替本账户真实调用验证。
- 当前默认选择 `gpt-image-2.6-flare`、`quality=high`、`complexity=medium`、JPEG 90。以细节、清晰主体和温暖的手绘质感为目标；不增加分镜中没有的明显人物或动物。该选择来自下述固定场景比较，不代表所有请求的性能保证。
- 成图后核对真实图像。只有关键角色/场景不符、重复主体等实质问题才重画，最多自动修正一次；最终失败说明未完成并可重试，不假装已经展示。用户取消、挂断或换会话后，迟到结果不能发布。
- 真实测试发现选景回复偶尔混有说明和两份 JSON，不能直接把所有文字拼接后解码。读取最后一个完整 JSON 对象，仍严格校验所需字段和类型；不把外围文字当作画面来源，不强制把字符串转换成布尔值。这个解析处理同样用于图片核验。
- 生成阶段显示简短状态，主窗口和桌宠共享状态。文字入口直接发布已核实的图和说明，避免再调用模型润色说明；同一轮重复工具调用复用已有结果。
- 电话在工具完成时立即发布图片；本机老师直接朗读核实说明，兼容云端声音的后续音频请求也不阻塞图片显示。桌宠聊天浮窗包含成图缩略图，点图打开主窗口。

## 验收与追踪

| ID | 必须验证的行为 |
| --- | --- |
| AI-001 | 识别用户截图口语及常见画图表达；否定、谈论绘画和故事内画画不误触发。 |
| AI-002 | 当前对话已有情节但没有保存故事时，文字和语音都能取得该上下文并出图。 |
| AI-003 | 无故事也能按明确的新主体画；当前新要求和纠正优先，不混入旧故事；无主体时诚实问清。 |
| AI-004 | 同一轮不重复生成；取消、挂断、换轮后的结果不落盘或挂到错误对话。 |
| AI-005 | 展示实际生成且核实的图片和说明，不使用固定图库顶替；不依赖额外模型回复才有成图。 |
| AI-006 | 质量/尺寸/压缩设置可核验；不匹配仅修正一次；失败可重试且不虚称成功。 |
| AI-007 | 文字和电话都有生成进度；慢请求不阻止挂断、收音和真正的新指令。 |
