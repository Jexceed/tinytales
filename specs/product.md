# 小小故事屋：产品基线

状态：已确认的持续约束。更新：2026-11-14。

用户的新指令可以改变这些决定，但不能在实现中无说明地丢失；改变时同时更新本文件、相关功能规格和验收。

| ID | 必须保留的行为 | 主要实现 / 验收入口 |
| --- | --- | --- |
| P-01 | 交付独立原生 macOS App；智能助手伴侣、沟通对话为主，不恢复网页或花哨内容大厅作为主入口。 | `TinyTalesApp`、`Views`、原生窗口验证 |
| P-02 | 统一角色为 AI 伙伴莉莉、彩虹独角兽；默认图标、聊天、桌宠一致，保留可选桌宠人物。文字与电话共用自然、连贯的人物描述，以性情和相处方式塑造角色。桌宠电话居中，主窗口和桌宠共享同一会话。 | `LilyPersona`、`DesktopPet`、`AppModel`、NativeTests |
| P-03 | 默认声音为用户已确认的 A「温柔老师」。默认电话、自动朗读、试听共用同一中文声线，用户后续明确选择继续保留；老师仅是声音风格，不把伙伴改成课堂老师或真人。 | `VoiceStyle`、`TeacherSpeech`、TeacherSpeechTests |
| P-04 | 一次接通持续交流，听与说保持双工，不逐句开关麦克风。附和不抢话；明确打断、纠正、问题或重要新内容能及时让出，不以特定口令或整段结束为前提。段落完整性是偏好，不能锁住话权。 | `RealtimeCall`、VoiceTurnTests、NaturalTurnTests |
| P-05 | 保留侧边栏；有清楚的会话选中状态。点击、切换、刷新不重排已有会话；空白新对话和欢迎语不创建占位会话，实际首条用户消息才创建。 | `AppModel`、NativeTests |
| P-06 | 首次文字空白入口提供少量可选话题，选择后填草稿，不擅自发送；直接语音入口不展示选题。 | `OpeningPrompt`、NativeTests、PhoneTests |
| P-07 | 正常聊天、问候、编故事不要求先找大人；连接配置不是每轮准入条件。特殊真实危险仍按既有内容处理，不借此打断普通交流。 | `CompanionEngine`、`PartnerTools`、内容回归 |
| P-08 | 连接保存一次并复用；更新复用持久签名、已有麦克风授权。App 不扫描文稿里的模型资源；不新增日常权限/密钥确认。 | `Credentials`、安装/签名脚本、权限诊断 |
| P-09 | 云端调用只统计，不恢复每日 60 次等人为上限。现有会话时长设置与工具循环边界分别管理；空白文字会话从首条有效输入开始计时，欢迎页待机不消耗会话时长。 | `LocalStore`、CompanionEngine、PhoneTests |
| P-10 | 故事设定以最新纠正为准，不能凭空编造共同经历；画图依据本轮指定画面与当前对话中的实际内容，不要求先保存故事，不拿固定图库替代。 | `StorySession`、`PartnerTools`、内容/配图回归 |
| P-11 | 聊天文字和音频保持流式体验；中文按意群自然表达，不把逗号或单字硬切成独立配音请求。 | `ResponseStream`、`TeacherSpeech`、语音规格 |
| P-12 | 原始聊天在进程会话中，常规录音不落盘；SQLite 保存设置、记忆、虚构故事摘要和统计。凭据不进入数据库/导出/安装包。 | `LocalStore`、`Credentials`、资源路径回归 |
| P-13 | 重要状态以明确标题、图标、颜色和动态反馈表达；主界面不堆实现术语或装饰性小字。 | `CallActivity`、`Views`、原生窗口检查 |
| P-14 | 莉莉有轻柔、多样的空闲动作和触摸回应；真实聊天/通话状态优先。动作不自动发言、不移动桌宠窗口、不调用云端；保留安静陪伴及系统减少动态效果。 | `PetBehavior`、`PetCanvas`、桌宠行为规格 |
