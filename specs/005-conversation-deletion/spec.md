# 删除历史对话

状态：已实现并安装 0.15.0；代码回归与临时窗口交互检查通过。日期：2026-11-14。产品基线：[product.md](../product.md)。

## 需求与原因

侧边栏只有打开历史对话的入口，用户无法在对话列表直接删除不需要的记录。会话同时包含运行中缓存、历史故事锚点和配图，不能只隐藏一行，否则刷新或重启会重新出现。

## 行为与边界

- 每条真实会话提供“⋯”菜单和右键“删除对话…”，包括相同标题的记录；操作使用稳定 ID，不能按标题删除。
- 只在用户选择删除后显示一次确认，包含目标标题、“删除”和“取消”。不增加家长验证、密钥或系统授权步骤。功能验证只删除临时合成数据，不替用户清理已有历史。
- 删除当前会话：停止当前生成、朗读和电话，清理该会话缓存、草稿和关联故事，返回新对话工作区，不选择相邻历史、不产生空白占位行。此前留在新对话工作区的未发草稿保留。
- 删除其他会话：当前选中、消息、草稿、正在处理的请求和通话保持原状；其余历史的相对顺序不变。
- 删除目标会话独占的故事摘要及配图，包括一段对话内关联的多个故事；仍被其他会话引用的故事/图片保留。无故事存档的普通聊天也能删除。
- 数据库删除以事务执行；失败时不先移除侧栏或缓存。成功后清除对应配图文件。目标已不存在时无副作用。
- 不能靠全局修改修订号清空所有会话。当前会话由取消和轮次标识拦截迟到回调；被明确删除的故事 ID 在本次进程内拒绝再次保存，避免旧工具结果复活记录。重启后没有存档可重新装载。
- 保持已有原始聊天不落盘、连接/签名复用、稳定排序、莉莉与独角兽、统一声音和桌宠行为。这里不增加回收站或云端数据删除能力。
- 原生/电话回归程序和隔离窗口夹具使用独立临时配图目录；清空测试数据库时不能触及应用正式配图。正式运行仍使用原 Application Support 目录。

## 验收与追踪

| ID | 必须验证的行为 |
| --- | --- |
| CD-001 | 同名会话按 ID 精确删除；菜单和右键入口可用，取消确认没有删除效果。 |
| CD-002 | 当前会话删除后返回未开始的新对话；刷新、切换和新建不能恢复旧缓存。 |
| CD-003 | 删除非当前会话保留当前选择、内容、草稿、其他缓存与相对顺序，不中断无关请求。 |
| CD-004 | 独占摘要与图片被删除、重开数据库后不出现；共享引用及其他数据保持。 |
| CD-005 | 正在生成或通话的当前会话可删除，迟到结果不能重新发布或保存。 |
| CD-006 | 无效目标无副作用；事务失败不部分删除；旧故事 ID 的迟到保存被拒绝。 |
| CD-007 | 删除测试和窗口夹具的数据库、配图均隔离；正式配图文件在验证前后保持不变。 |
