# 主窗口童趣界面

状态：0.20.1（build 39）降低主页面亮度。0.20.0（build 38）已实现并安装；尚未做儿童实际使用观察。更新：2026-11-19。产品基线：[product.md](../product.md)。

## 需求与变更原因

用户反馈：进入主窗口后的界面和交互“有点太简单”，希望让孩子更感兴趣。原界面以白卡片和单色文字为主，欢迎页只有一张静态头像，等待时只有系统转圈，通话时主区域除底部面板外没有莉莉的反应。

目标是让孩子在主窗口里“看得到莉莉在陪着自己”：有色彩、有回应、有一点会动的东西，同时不改变对话优先、会话侧栏、声音、内容和权限等既有约束。

## 0.20.1 变更：主页面柔和不刺眼

用户反馈（2026-11-19）：改版整体很好，但主页面“有点太亮、刺眼”。原因是大面积接近纯白：对话区背景顶部相对亮度约 0.97，莉莉气泡、输入框、问候气泡和标题栏是纯白或高不透明白色（1.0），再叠加卡片左上角的白色高光。

替代做法：不改变配色风格和童趣元素，只把大面积表面压到柔和的奶油淡紫色。
- 对话区背景改为偏灰的淡紫/奶油渐变，相对亮度不超过 0.85；云朵透明度降低，避免在背景上形成亮斑。
- 莉莉气泡、输入框、问候气泡、思考气泡、选中的会话行、配图相框使用同一奶油色表面，相对亮度不超过 0.93；标题栏用半透明的淡紫奶油色。
- 侧栏渐变同步略暗，保持与对话区的层次；卡片左上角高光减弱。
- 正文墨色与这些表面的对比度保持 ≥ 7:1（WCAG AAA），亮度降低不能牺牲阅读。
- 状态色（通话绿/金/粉、挂断红）、按钮渐变和插画本身不调暗。

## 设计决定与边界

- **故事天空背景**：对话区使用柔和的奶油→淡紫渐变，加少量缓慢漂浮的云朵和闪烁的小星星。透明度低，不影响正文阅读；系统“减少动态效果”时完全静止。背景不可点击，也不是内容入口（P-01 不恢复内容大厅）。
- **欢迎页莉莉舞台**：空白会话中央显示大号莉莉，站在柔光圆台上，背后有彩虹弧。轻轻上下浮动、偶尔眨眼。孩子点一下莉莉，莉莉挥手、轻跳，并飘出几颗爱心和星星，约 1.6 秒后恢复；连点有短暂冷却，不会刷屏。
  - 点莉莉只是本机视觉回应：不朗读、不发送消息、不接通电话、不调用云端（与桌宠 PB-002/PB-007 一致）。
  - 欢迎语按本机时间问候（早上好 / 下午好 / 晚上好），用对话气泡样式指向莉莉；直接语音入口仍显示“莉莉在这里”，不展示选题（P-06）。
- **通话时莉莉有反应**：通话中且当前会话还没有消息时，舞台上的莉莉按真实通话状态切换姿态：正在接通→挥手打招呼，在听→侧耳倾听、在想→托腮思考、在讲→开口讲话，背后的光环颜色与通话状态色一致（绿/金/粉），并随声音电平轻轻起伏。真实通话状态优先于点击回应；静音时显示安静姿态和灰色光环。
- **开场选题变成彩色卡片**：四个选项各有自己的颜色和填充图标（太阳、书本、月亮、雨伞），更高、更大的圆角卡片，悬停时轻微抬起。点击仍只填草稿，不擅自发送（P-06）。
- **聊天气泡更有生气**：新消息以轻柔弹出出现；莉莉头像放进彩色圆环，孩子的头像是暖黄色笑脸徽章。后续建议气泡用桃色/天蓝/薄荷轮换颜色，字更大，悬停抬起。“再听”使用彩色胶囊按钮。
- **等待不再是系统转圈**：莉莉思考时显示托腮的小莉莉和跳动的三个圆点；流式生成中的圆点也会跳动。画图进度沿用原有文案。
- **侧栏更亮眼**：顶部品牌区加彩虹点缀；“新对话”改为渐变按钮。每个会话的图标放在彩色圆形徽章里，颜色由会话 ID 稳定决定（不随点击、切换、刷新或排序变化）。选中态的高亮、左侧色条与无障碍“已选中”保持（P-05）。生成中/新回复/失败状态标记保持。
- **配图与词卡**：配图加白色相框和投影，像绘本的一页；词卡拼音着色、汉字更大。
- **输入区**：发送和电话按钮使用渐变与柔和投影；“+”放进圆形底色。通话状态色、挂断红色、停下按钮等状态表达不变（P-13）。
- **动效边界**：所有自发动效（浮动、眨眼、云朵、星星、光环起伏、气泡弹出）在系统“减少动态效果”时关闭；点击回应只显示静态挥手姿态，不出现粒子。聊天气泡里的小头像保持静态，不参与自发表演（沿用桌宠规格中“主界面静态头像不参加自发表演”，只有欢迎舞台的大莉莉有浮动和眨眼）。
- 不新增文字说明性小字、实现术语或装饰性标签（P-13）；不新增网络请求、权限或设置项。

原决定与替代：桌宠规格原写“主界面静态头像不参加自发表演”。本次用户明确要求让主界面更吸引孩子，因此仅欢迎/通话舞台上的大莉莉允许轻浮动与眨眼（受“减少动态效果”约束）；聊天气泡和侧栏头像仍静态。

## 验收与追踪

回归测试位于 [PlayfulUITests.swift](../../macos/Tests/PlayfulUITests.swift)，注册到原生测试集；名称包含稳定 ID。

| ID | 必须验证的行为 |
| --- | --- |
| UI-001 | 会话徽章颜色由 ID 稳定决定：重复计算、重启后、列表重排或切换会话时不变；不同会话能分到多种颜色。 |
| UI-002 | 舞台姿态：真实通话状态（连接/在听/在想/在讲/静音）优先于点击回应；空闲时偶尔眨眼，减少动态效果时不眨眼。 |
| UI-003 | 点击莉莉的回应有限时长并有冷却，结束后回到空闲；点击回应不改变会话、草稿、消息或通话，也不触发朗读。 |
| UI-004 | 减少动态效果时浮动幅度、粒子数量和气泡弹出均为零；正常时幅度受限，不移动窗口。 |
| UI-005 | 欢迎语按本机时段问候，文字入口与语音入口区分；选题卡片仍只填草稿不发送。 |
| UI-006 | 主页面大面积表面不刺眼：背景相对亮度 ≤ 0.85，气泡/输入框等表面 ≤ 0.93 且不是纯白；正文墨色对比度 ≥ 7:1。 |

- 代码测试：原生 167/167 通过（新增 UI-006 亮度与对比度回归，并确认旧的刺眼背景会被该界限拒绝）；电话 150/150 通过；规格检查通过。
