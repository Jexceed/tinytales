# 主窗口童趣界面

状态：已安装 0.21.4（build 44）。本版修复共享书签缩略图、词卡朗读、挂断后的欢迎入口和配图动效。保留 0.21.3 的小女孩头像与紧凑“重说 / 修改”按钮。更新于 2026-11-19。产品基线见 [product.md](../product.md)。

## 需求与变更原因

### 0.21.4 合入前复核

两个运行中的会话可以读同一本书。原实现用书签 ID 补齐运行会话的缩略图，导致没有画过图的会话显示了别处的画。现按会话消息选图，只有存档行能直接查故事配图；打开存档时保留当时已有的封面。刷新检测到归档目录或本进程的配图写入发生变化时，在后台重建索引。原实现的普通刷新会逐份读取配图元数据，1000 张虚构配图的本机复测中，每次约占用主线程 39 毫秒。

词卡的可用性以当前会话和消息实际状态为准。只有莉莉问候、孩子尚未发言就挂断时，主窗口保留问候记录并恢复大号通话入口，以首条有效用户消息区分会话是否开始。

原生窗口测得配图粒子在 1.8 秒后已经不可见，第六秒仍在刷新。庆祝改为有限帧，并按配图 ID 在新图时间窗内只领取一次，快速切换会话也不能重播。

用户反馈：进入主窗口后的界面和交互“有点太简单”，希望让孩子更感兴趣。原界面以白卡片和单色文字为主，欢迎页只有一张静态头像，等待时只有系统转圈，通话时主区域除底部面板外没有莉莉的反应。

目标是让孩子在主窗口里“看得到莉莉在陪着自己”：有色彩、有回应、有一点会动的东西，同时不改变对话优先、会话侧栏、声音、内容和权限等既有约束。

## 0.21.3 变更：更紧凑、有区分的“重说 / 修改”

用户要求（2026-11-19，附截图）：这两个按钮更紧凑一些，同时在样式或颜色上有区分。原状态：两枚同样的奶油底桃色边胶囊，14 号字、约 30pt 高，彼此间距 8pt，与气泡相距 8pt，看起来偏大且分不出主次。

- 尺寸收紧：12 号字、10 号图标，胶囊约 20pt 高，按钮间距 5pt，与气泡间距 5pt，右侧略内收与气泡圆角对齐。
- 主次区分：“重说”是孩子自己最常用的动作，用暖珊瑚色渐变实心胶囊、白字；“修改”偏家长使用，用奶油底、淡紫描边、紫色字的轻量描边胶囊。两者图标保持（↺ / ✎）。
- 出现条件、点击行为、按钮名称不变（UI-013）。通话面板与桌宠里的同名入口保持原系统按钮样式，不在本次范围。

## 0.21.2 变更：小女孩头像与“修改”

用户要求（2026-11-19，附截图）：1. 孩子人物改用小女孩形象；2. “改文字”换成“修改”。

- 孩子头像换成同风格的小女孩插画（约五岁，两个小辫子扎桃色发绳，桃色圆领上衣，暖奶油底），取代 0.21.1 的中性小朋友形象；文件名、圆形裁切、尺寸、来源记录方式不变。
- 语音纠正按钮“改文字”统一改名为“修改”：主窗口孩子气泡下方的胶囊、通话面板输入预览、桌宠紧凑面板中的同一入口都改，行为不变。语音可靠性规格中的入口名称同步更新。

## 0.21.1 变更：孩子头像与“重说 / 改文字”排布

用户反馈（2026-11-19，附截图）：对话里“我说”的形象太难看；“重说、改文字”的排布很奇怪。原因：孩子头像只是系统笑脸符号放在橙色圆里，和莉莉的立体绘本形象风格割裂；纠正按钮是两段小号紫色文字，悬在橙色气泡内右下角，还为了放它们把短气泡强行撑宽到 220pt，留出一块空白。

替代做法：
- 孩子头像换成与莉莉同风格的原创插画：中性、约五岁的小朋友半身像，软陶绘本质感，暖奶油底色，圆形裁切并加桃色细边，尺寸与莉莉头像一致（34pt）。插画随包提供（`Brand/child-avatar.png`），生成来源和提示词记录在同目录 `child-avatar.json`；资源缺失时回退为原来的笑脸徽章。
- “重说 / 改文字”移出气泡，放在孩子气泡正下方、右对齐，做成两枚带图标的小胶囊按钮（奶油底、桃色边、暖棕文字），和气泡同属孩子一侧的配色。气泡宽度只按文字计算，不再为按钮撑宽。按钮出现的条件、点击行为不变（仍是 `retryVoiceInput` / `editVoiceInput`，见语音可靠性规格）。

## 0.21.0 变更：从 5～6 岁孩子的视角补齐

用户确认（2026-11-19）按建议做第一批。5～6 岁孩子大多不识字、不会打字、鼠标不准、耐心短，喜欢看到自己的作品和即时回应。现状问题：欢迎页最显眼的是文字问候、文字选题卡和“写给莉莉…”输入框，真正能用的“打电话”在右下角；侧栏只有文字标题；通话中一有消息大舞台就消失；画图要等二三十秒只有一行字；词卡只能看。

- **欢迎页大“和莉莉说话”按钮**：空白会话且未通话时，在问候气泡下方显示大号“和莉莉说话”按钮（麦克风图标、渐变胶囊、轻柔呼吸光晕），点击与右下角电话按钮完全相同（`toggleCall`）。右下角电话按钮保留。文字入口的选题卡照旧只填草稿；直接语音入口仍不显示选题（P-06），挂断后回到空白会话同样能一键再打。会话开始或通话中不显示。窗口较矮（如最小 1000×600）时舞台缩小、上边距收紧，保证莉莉、问候和这个按钮都在首屏内，选题卡可向下滚动。
- **侧栏用画认会话**：会话里有配图时，侧栏圆形徽章换成该会话最新配图的小缩略图。当前/后台会话取会话中最新的有效配图，没有画过图但看过随包图库插画时用该插画；存档会话按故事 ID 取已保存的最新配图。没有配图保持彩色徽章；生成中/失败标记优先。缩略图按需缩小并缓存，不改变标题、时间、顺序或选中态（P-05）。
- **通话中莉莉一直在**：通话面板左侧的圆球换成莉莉头像，按真实状态换姿态（接通挥手、在听侧耳、在想托腮、在讲张嘴、静音安静），外圈和右下角图标沿用原状态色与图标（P-13）；在听/在讲时外圈随声音起伏。减少动态效果时不换嘴型、不起伏。桌宠里的紧凑电话球不变。
- **画图等待与完成庆祝**：识别画图进度（选画面、画画、补细节、快画好；电话中的画图状态）时，等待气泡换成“莉莉在画画”：小画框一开始就有几团颜色，再慢慢晕开填满，配原有进度文字。新画好的图第一次出现时撒一圈星星和爱心；以配图文件的保存时间判断新旧，切回旧会话不重放。减少动态效果时画框静止、不撒星星。
- **词卡点一下读出来**：点词卡由莉莉用当前统一声音读出汉字（与“再听”同一路径，P-03）。通话中不朗读，避免与电话抢声道；生成中不可点。

动效和缩略图均在本机处理。词卡沿用“再听”的声音选择和调用统计，默认老师声线在本机生成，主动选用云端声线时点读会使用已配置的服务。

## 0.20.1 变更：主页面柔和不刺眼

用户反馈（2026-11-19）：改版整体很好，但主页面“有点太亮、刺眼”。原因是大面积接近纯白：对话区背景顶部相对亮度约 0.97，莉莉气泡、输入框、问候气泡和标题栏是纯白或高不透明白色（1.0），再叠加卡片左上角的白色高光。

替代做法：不改变配色风格和童趣元素，只把大面积表面压到柔和的奶油淡紫色。
- 对话区背景改为偏灰的淡紫/奶油渐变，相对亮度不超过 0.85；云朵透明度降低，避免在背景上形成亮斑。
- 莉莉气泡、输入框、问候气泡、思考气泡、选中的会话行、配图相框使用同一奶油色表面，相对亮度不超过 0.93；标题栏用半透明的淡紫奶油色。
- 侧栏渐变同步略暗，保持与对话区的层次；卡片左上角高光减弱。
- 正文墨色与这些表面的对比度保持 ≥ 7:1（WCAG AAA），亮度降低不能牺牲阅读。
- 状态色（通话绿/金/粉、挂断红）、按钮渐变和插画本身不调暗。

## 设计决定与边界

- **故事天空背景**：对话区使用柔和的奶油→淡紫渐变，加少量缓慢漂浮的云朵和闪烁的小星星。透明度低，不影响正文阅读；系统“减少动态效果”时完全静止。背景不可点击，也不是内容入口（P-01 不恢复内容大厅）。
- **欢迎页莉莉舞台**：空白会话中央显示大号莉莉，站在柔光圆台上，背后有彩虹弧。轻轻上下浮动、偶尔眨眼。孩子点一下莉莉，莉莉挥手、轻跳，并飘出几颗爱心和星星，约 1.6 秒后恢复；连点有短暂冷却，不会刷屏。
  - 点莉莉只是本机视觉回应：不朗读、不发送消息、不接通电话、不调用云端（与桌宠 PB-002/PB-007 一致）。
  - 欢迎语按本机时间问候（早上好 / 下午好 / 晚上好），用对话气泡样式指向莉莉；直接语音入口仍显示“莉莉在这里”，不展示选题（P-06）。
- **通话时莉莉有反应**：通话中且当前会话还没有消息时，舞台上的莉莉按真实通话状态切换姿态：正在接通→挥手打招呼，在听→侧耳倾听、在想→托腮思考、在讲→开口讲话，背后的光环颜色与通话状态色一致（绿/金/粉），并随声音电平轻轻起伏。真实通话状态优先于点击回应；静音时显示安静姿态和灰色光环。
- **开场选题变成彩色卡片**：四个选项各有自己的颜色和填充图标（太阳、书本、月亮、雨伞），更高、更大的圆角卡片，悬停时轻微抬起。点击仍只填草稿，不擅自发送（P-06）。
- **聊天气泡更有生气**：新消息以轻柔弹出出现；莉莉头像放进彩色圆环，孩子的头像是暖黄色笑脸徽章。后续建议气泡用桃色/天蓝/薄荷轮换颜色，字更大，悬停抬起。“再听”使用彩色胶囊按钮。
- **等待不再是系统转圈**：莉莉思考时显示托腮的小莉莉和跳动的三个圆点；流式生成中的圆点也会跳动。画图进度沿用原有文案。
- **侧栏更亮眼**：顶部品牌区加彩虹点缀；“新对话”改为渐变按钮。每个会话的图标放在彩色圆形徽章里，颜色由会话 ID 稳定决定（不随点击、切换、刷新或排序变化）。选中态的高亮、左侧色条与无障碍“已选中”保持（P-05）。生成中/新回复/失败状态标记保持。
- **配图与词卡**：配图加白色相框和投影，像绘本的一页；词卡拼音着色、汉字更大。
- **输入区**：发送和电话按钮使用渐变与柔和投影；“+”放进圆形底色。通话状态色、挂断红色、停下按钮等状态表达不变（P-13）。
- **动效边界**：所有自发动效（浮动、眨眼、云朵、星星、光环起伏、气泡弹出）在系统“减少动态效果”时关闭；点击回应只显示静态挥手姿态，不出现粒子。聊天气泡里的小头像保持静态，不参与自发表演（沿用桌宠规格中“主界面静态头像不参加自发表演”，只有欢迎舞台的大莉莉有浮动和眨眼）。
- 不新增文字说明性小字、实现术语或装饰性标签（P-13）；不新增网络请求、权限或设置项。

原决定与替代：桌宠规格原写“主界面静态头像不参加自发表演”。本次用户明确要求让主界面更吸引孩子，因此仅欢迎/通话舞台上的大莉莉允许轻浮动与眨眼（受“减少动态效果”约束）；聊天气泡和侧栏头像仍静态。
