# 对话工具与设置

0.19.1（build 37）。适用于原生主窗口、桌宠共用的文字与电话入口，产品约束见[产品基线](../product.md)。

## 需求与变更原因

莉莉可以查记忆、查找和读取故事、查经典、展示图库、画图、保存故事、提出记忆候选和展示词卡。检查中发现，关闭记忆后模型仍能看到记忆工具，已满的记忆库会让整轮回复提交失败。画图与其他工具同轮返回时，还会把未经最终文字审核的候选与故事一并写入。文字聊天在本机拦下的用户原话也可能随接通电话时的历史发出。

| 孩子想做的事 | 工具分工 |
| --- | --- |
| 打招呼、聊天、说说今天 | 莉莉可以直接回应。主窗口与桌宠共享同一段对话。 |
| 接着编以前的故事 | `find_stories` 按线索找书，`read_story` 选中真实书签并取回进度，`save_story` 可更新虚构设定。普通叙事回复通过审核后自动留书签。 |
| 看一幅画、画刚讲的情节 | `show_picture` 从随包图库取实图，`illustrate_story` 根据对话选景、生成并核对新图。 |
| 问诗句或一个词 | `lookup_classics` 提供有出处的原文和解释，`show_word` 在聊天中展示汉字、拼音和英文。 |
| 记住兴趣、回想偏好 | `propose_memory` 提出候选，家长确认后 `recall_memories` 才能读到。 |

## 决定与验收

| ID | 验收场景 |
| --- | --- |
| TL-001 | 记忆关闭时，文字与电话均不提供两个记忆工具。即使收到旧调用，也不读取、写入或显示记忆活动。开启时只有带本轮有效原话的候选可进入待确认区，重复、已满或无依据的候选不妨碍正常回复与故事保存。 |
| TL-002 | 词卡的汉字、拼音、英文均须有内容，三栏都检查隐私及不适合展示的内容。无效词卡可以在同轮修正，或直接完成普通回复。 |
| TL-003 | 直接交付经核对的配图时只保存配图。即使同轮模型还提出记忆或故事，也不能借配图提前提交这些写入或声称已保存。 |
| TL-004 | 本机已拦下的文字（包括通话中键入或修改后发送的文字）不发给电话，也不随之后的文字或电话历史重发。普通对话仍可衔接。接通中输入的草稿保留，接通后可以发送一次。 |
| TL-005 | 同轮更新虚构故事再查找、读取时，应返回最新暂存的标题、摘要和同一个 ID；放弃这一轮不改已有书签。找不到的故事应如实返回。 |
| TL-006 | 模型每轮最多发起 3 批、执行 8 次工具调用。达到额度后仍可给出最终答复。电话的问候和配图朗读直接说话；超额调用不执行、不提交暂存数据，电话仍可接收下一句。 |
| TL-007 | 当前会话已有进行中的虚构故事时，孩子用自然动作或选择继续共创（未转向现实科学问答、拒绝故事或请求画图），电话与文字均保持叙事分段并自动推进同一故事书签。 |
| TL-008 | 孩子表达“不知道聊什么/你挑个故事”等开放求助时，文字与电话从随包 `ContentLibrary` 注入精选故事与探索灵感（不恢复内容大厅）；主窗口最新助手消息展示可点击的 `suggestions` 后续建议。 |
| TL-009 | 待确认记忆数量在主窗口设置入口与家长页清晰提示；单纯批准（`pending -> approved`）新记忆保留正在进行的对话与后台会话缓存，修改或删除已记住内容才刷新会话；删除连接具备二次确认防儿童误触。 |
| TL-010 | 有故事书签时，日常聊天和生活感受不写入故事；明确续讲、选择故事角色的行动仍可推进原书签。被拦截输入按消息记录决定，在换入口时排除。 |

0.19.1 修改原因：上一版把大部分没有命中排除词的电话发言都当作共创，导致聊看牙也写入原故事。存档改为需要正向叙事依据。

电话原先在超过工具额度时直接挂断，问候时也会继承全套工具。额度保护的是单轮工作，通话连接可以继续复用。

调节时长的验收见[会话后台生成](../009-background-conversations/spec.md)。查看、生成和拒绝图片的验收见[对话里的画图](../004-conversation-artwork/spec.md)。完整篇名的匹配见[成语与古诗词资料](../006-classical-knowledge/spec.md)。
