# Story worlds v1

Generated with the built-in `image_gen` tool. This is a single six-cell atlas; original generated output is preserved. Workspace asset: `macos/Resources/Library/story-worlds-v1.png`. `scripts/export-story-worlds.swift` extracts the six square regions without changing their content into `macos/Resources/Scenes/world-{forest,stars,ocean,friends,magic,cozy}.png` and matching vision copies.

These are theme illustrations and curated pictures. They are not presented as newly generated illustrations for a child's ongoing story.

## Prompt

Create ONE production illustration atlas for a native macOS children's storytelling app called TinyTales, aimed at ages 5–6. This is a single 3-column by 2-row grid of six equally sized square picture-book cover illustrations, edge-to-edge cells with clean straight boundaries, no outer margin, no gaps, no lettering, no text, no numbers, no UI. Exact ordered cells: top left a friendly mint baby dinosaur holding a tiny glowing seed by a woodland path; top middle a small white rabbit beside a pearly crescent moon in a magical starry sky; top right a curious little otter exploring an underwater coral garden with bubbles and a sea turtle. Bottom left a tiny kind hedgehog sharing an orange umbrella with a rabbit by a puddle; bottom middle a cute pastel rainbow unicorn reading a purple storybook on a golden cloud near a rainbow bridge; bottom right a sleepy small bear in a cozy treehouse reading a book by warm lantern light, peaceful twilight garden. Style consistent throughout: polished richly detailed children's storybook art with soft dimensional characters, warm cinematic light, tactile painterly scenery, rounded forms, joyful curiosity, pastel violet and peach accents, expressive kind eyes. Not pixel art. The scenes must be distinct miniature worlds, not simple flat color blocks. Each cell contains ONE coherent moment and each animal only once. Compose main subjects within the central 75% of each cell so the illustrations tolerate cropping as book covers. Strict uniform 3x2 atlas layout.
